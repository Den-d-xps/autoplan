# Changelog

## [1.0.0] - 2026-02-24

### Новые возможности

- **Парсинг данных** — при входе в систему автоматически загружаются доступные пользователю кинотеатры и данные профиля (имя, аватар)
- **Инициализация приложения** — добавлена инициализация при запуске: приложение автоматически восстанавливает состояние сессии и применяет сохранённые настройки
- **Кинотеатры по умолчанию** — добавлена возможность задать список кинотеатров по умолчанию, которые будут предвыбраны при запуске
- **Сохранение настроек** — настройки приложения теперь сохраняются между сессиями
- **Страница информации** — добавлена страница с информацией о приложении и версии
- **Бейдж пользователя** — в интерфейсе отображается имя и аватар текущего пользователя Kinoplan
- **Кнопки очистки задач** — добавлены кнопки для очистки очереди задач (все задачи / только завершённые)

### Исправления

- **fix:check-cpl-chrono** — исправлена проверка хронологии CPL при расстановке световых макросов
